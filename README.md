# Graper Pricing Tool

Ferramenta para precificação de serviços de impressão 3D.

**Versão:** 0.1.0


## Sobre o projeto
Criado para auxiliar o usuario que trabalha com impressões 3D, a precificar corretamente cada serviço.

## Funcionalidades

- Cálculo do custo do filamento
- Cálculo do consumo de energia
- Cálculo do custo da máquina
- Cálculo de custos fixos
- Definição de margem de lucro
- Valor final sugerido

## Técnologias

- HTML5 e CSS3
- JavaScript (ES6+)

## História de desenvolvimento
Este projeto surgiu quando minha esposa e eu começamos a trabalhar com impressão 3D. Percebemos que definir um preço justo para cada impressão era mais difícil do que imaginávamos. Como eu estava estudando JavaScript, decidi transformar esse problema real em um projeto de aprendizado.

O desenvolvimento começou em 12/07/2026. Meu objetivo foi implementar toda a lógica por conta própria, utilizando IA apenas para esclarecer conceitos e validar raciocínios, evitando solicitar soluções prontas em código.



# English version - Graper Pricing Tool

Ferramenta para precificação de serviços de impressão 3D.

**Versão:** 0.1.0


## About
Designed to help users who work with 3D printing correctly price each service.

## Features

- Filament cost calculation
- Energy consumption calculation
- Machine cost calculation
- Fixed cost calculation
- Profit margin setting
- Suggested final price

## Technologies

- HTML5 and CSS3
- JavaScript (ES6+)

## Development History
This project came about when my wife and I started working with 3D printing. We realized that setting a fair price for each print was harder than we had imagined. Since I was studying JavaScript, I decided to turn this real-world problem into a learning project.

Development began on July 12, 2026. My goal was to implement all the logic on my own, using AI only to clarify concepts and validate my reasoning, and avoiding the use of ready-made code solutions.
